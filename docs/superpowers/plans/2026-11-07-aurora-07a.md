# Project Aurora 0.7A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Integrar dois avatares GLB originais e uma sala brasileira visualmente aprimorada, preservando jogabilidade.

**Architecture:** Blender offline gera malhas, rig e animações reproduzíveis. Um cache GLB compartilha geometria e materiais Colorbeat, clona esqueletos e normaliza escala/pivô. A sala estende os helpers métricos existentes e usa batching estático.

**Tech Stack:** Three.js, JavaScript, Vite, Blender 4.3/bpy, GLB.

**Spec:** Pedido Project Aurora 0.7A do usuário e `docs/AUDITORIA-07A.md`.

## Global Constraints

- Não alterar main diretamente. Branch feat/aurora-07a, entrega por Pull Request.
- Nenhum serviço pago, crédito IA ou nova missão. Aparências fictícias personalizáveis.
- Preservar teclado, mouse, multitouch, Chromebook, saves e qualidades Baixa/Média/Alta.
- Licenciar e documentar todos os assets, gerar arquivos GLB reais.

## Review Focus

- Falha de rede deve manter manequim jogável.
- Substituições assíncronas concorrentes não podem reanexar modelo antigo nem vazar recursos.
- Esqueletos independentes, geometria/material compartilhados, descarte único do cache.
- Portas e passagem central precisam continuar acessíveis.
- Cabelo/roupas devem acompanhar bones; sombra e contorno não duplicam personagem.
